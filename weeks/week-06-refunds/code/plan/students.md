## Как подписаны коммиты

У каждого в git должны быть выставлены его собственные имя и почта:

```bash
git config user.name  "Alibi Takhtanov"
git config user.email "takhtanovalb@gmail.com"
```

Почта должна совпадать с той, что привязана к аккаунту GitHub, иначе коммит не
свяжется с профилем и в графе вклада не появится.

Каждый коммитит **со своего компьютера и под своим именем**. Готовые команды на
каждую задачу лежат в `weeks/week-NN-*/S<N>.md` — скопировать и выполнить, минута
на задачу.

## Ревью

Все PR смотрит и вливает **капитан (S1)**. Друг друга не ревьюим: одно место
принятия решений — меньше путаницы и не бывает «а я думал, ты посмотришь».

Свой собственный PR капитан апрувить не может (GitHub не даёт апрувить себя),
поэтому в защите ветки галочка *Do not allow bypassing the above settings*
оставлена выключенной: капитан вливает свою работу без апрува, но только с
зелёным CI.
