**1. Jira.** Перетащите задачу из `To Do` в `In Progress`. Делайте это в тот день, когда садитесь за неё, — не раньше.

**2. Создайте ветку.** Имя уже подставлено, копируйте как есть:

```bash
git checkout week-02 && git pull
git checkout -b week-02-abylay-BF-18
```

**3. Что сделать с файлами:**

| | Файл | Примечание |
| --- | --- | --- |
| создать | `web/src/lib/api.ts` | ~80 строк, прямой `:8080` |
| создать | `web/src/lib/types.ts` | — |
| создать | `web/src/lib/format.ts` | самодельные форматтеры денег и дат |
| создать | `web/src/lib/env.ts` | адрес API читался вручную |

Трогать можно **только эти файлы**. Если нужен чужой — напишите его владельцу, сами не правьте.

> **Пишете с нуля:** `web/src/lib/format.ts`, `web/src/lib/env.ts`. Этих файлов нет в готовом проекте — они временные и позже удаляются, поэтому в `code/` на их месте только пометка. Сделайте их маленькими и простыми, по смыслу из примечания.

> **Файлы из `code/` финальные** и импортируют то, чего в проекте ещё нет (i18n, авторизацию и т.п.). Такие импорты и код, который на них опирается, **уберите** — иначе проверка ниже не пройдёт. Главное, чтобы собиралось сейчас.

**4. Проверьте, что собирается:**

```bash
cd web && npm install && cd ..
make web-check     # линт, типы и тесты фронта
```

Красный результат — не коммитим, чиним.

**5. Коммит и пуш:**

```bash
git add -A web/src/lib/api.ts web/src/lib/env.ts web/src/lib/format.ts \
        web/src/lib/types.ts
git commit -m "BF-18 Add the API client"
git push -u origin week-02-abylay-BF-18
```

Сообщение коммита — **дословно название задачи**, с номером впереди: по нему Jira сама свяжет коммит с задачей.
