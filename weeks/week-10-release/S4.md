## Прежде чем начать

**Один раз на компьютере** — чтобы коммит ушёл под вашим именем и связался с вашим профилем GitHub:

```bash
git config user.name  "Alinur Burlybayev"
git config user.email "почта-вашего-аккаунта-github"
```

> У вас ещё нет аккаунта GitHub. Заведите его, попросите капитана добавить вас в репозиторий и подставьте почту аккаунта в команду выше.

**Ветку недели создаёт капитан** в понедельник утром. Если команда `git checkout week-10` пишет, что такой ветки нет, — подождите капитана, ничего не создавайте сами.

**Задачи в Jira заводит капитан.** Вы их только двигаете по колонкам: `In Progress` когда начали, `In Review` когда открыли PR. В `Done` переводит капитан после слияния.
