Таблицы ниже говорят, **что** тронуть. Что именно написать:

| Случай | Куда смотреть |
| --- | --- |
| обычный файл | `weeks/week-10-release/code/<путь>` — как он выглядит в готовом проекте |

## Если что-то пошло не так

| Ситуация | Что делать |
| --- | --- |
| `git checkout week-10` пишет, что ветки нет | Капитан ещё не открыл неделю. Подождите, сами не создавайте. |
| Проверка сборки красная | Чините, пока не станет зелёной. Не коммитьте красное. |
| Забыли файл в коммите | Добавьте вторым коммитом в ту же ветку и запушьте. |
| Нужен чужой файл | Напишите его владельцу. Сами не правите никогда. |
| Не успеваете к пятнице | Скажите капитану заранее. Задача переедет на следующую неделю **со своим номером**, новую взамен не заводят. |
| Открыли PR в `main` вместо недели | Закройте его и откройте заново с base `week-10`. |
