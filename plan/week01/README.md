## Как запустить

Каждый скрипт — одна задача одного человека. Запускает **сам этот человек**,
когда садится за этот компьютер. Скрипт копирует файлы во временную копию
репозитория, коммитит под именем владельца задачи и пушит его ветку. Основная
папка `~/Desktop/ticket-project` не трогается.

```bash
bash ~/Desktop/bilet/plan/week01/S1-BF-6-fix.sh
bash ~/Desktop/bilet/plan/week01/S2-BF-9.sh
bash ~/Desktop/bilet/plan/week01/S4-BF-11.sh
bash ~/Desktop/bilet/plan/week01/S5-BF-12.sh
bash ~/Desktop/bilet/plan/week01/S5-BF-13.sh      # только после BF-12
```

Проверить без пуша: `DRY_RUN=1 bash …/S2-BF-9.sh` — коммит создаётся и сразу
удаляется.
