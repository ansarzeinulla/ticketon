### `BF-72 Create campaigns and promo codes`

**1. Jira.** Перетащите задачу из `To Do` в `In Progress`. Сделайте это утром того дня, когда начинаете, — не раньше.

**2. Создайте ветку:**

```bash
git checkout phase-09 && git pull
git checkout -b phase-09/<ваше-имя>-BF-72
```

Замените `<ваше-имя>` на своё: ветка должна называться, например, `phase-09/aslan-BF-72`.

**3. Что сделать с файлами:**

| | Файл | Примечание |

| создать | `api/internal/api/handlers_campaigns.go` | — |
| создать | `api/internal/api/handlers_promo.go` | — |

Трогать можно **только эти файлы**. Если кажется, что нужен чужой — напишите его владельцу, не правьте сами.

**4. Проверьте, что собирается:**

```bash

```

```bash

git push -u origin phase-09/<ваше-имя>-BF-72
```

Сообщение коммита — **дословно название задачи**. Не «похожее», а то же самое: по нему Jira сама свяжет коммит с задачей.

- **заголовок:** `BF-72 Create campaigns and promo codes`

Нажмите **Create pull request**.

**7. Jira.** Перетащите задачу в `In Review` и ждите.

Дальше PR смотрит капитан. Он же его вливает и переводит задачу в `Done` — сами не вливайте и не закрывайте.

## Кто смотрит ваш PR

Все PR в команде смотрит и вливает **капитан (S1)**. Он проверяет, что файлы только из вашей зоны, что коммит один и назван как задача, и что CI зелёный. Он же вливает PR и переводит задачу в `Done`.

Друг друга не ревьюим: одно место принятия решений — меньше путаницы и не бывает «а я думал, ты посмотришь».

---

## Если что-то пошло не так

| Ситуация | Что делать |
| --- | --- |
| CI покраснел | Чините у себя, делаете ещё коммит в ту же ветку, пушите. PR обновится сам. |
| Капитан вернул с замечаниями | Правите, коммитите в ту же ветку, пишете в PR «готово». Новый PR не нужен. |
| Забыли файл в коммите | Добавляете вторым коммитом в ту же ветку. Правило «одна задача — один коммит» про то, что приходит один смысловой шаг, а не про запрет себя исправлять. |
| Не успеваете к концу фазы | Говорите на разборе. Задача переезжает в следующую фазу **со своим номером**, новую взамен не заводят. |
| Нужен чужой файл | Пишете владельцу. Сами не правите никогда. |
